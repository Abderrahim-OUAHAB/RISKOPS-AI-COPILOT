# Pitch entretien

## Pitch court

J'ai construit AI RiskOps Copilot, un assistant IA qui aide une entreprise à détecter les risques clients, contrats et paiements à partir de documents et données internes.

Le projet combine FastAPI, PostgreSQL, pgvector, RAG, machine learning, agents IA, MLOps et monitoring.

## Pitch technique

Le projet est structuré comme une application IA complète.

Le frontend Streamlit sert à tester le produit.

Le backend FastAPI expose les fonctionnalités.

PostgreSQL stocke les données métier.

pgvector prépare la recherche sémantique.

LlamaIndex sera utilisé pour construire le RAG.

XGBoost prédira le churn client.

MLflow suivra les expériences ML.

LangGraph orchestrera l'agent IA.

Docker rend le projet reproductible.

## Valeur business

Le système aide un manager à répondre à une question importante:

Quels risques dois-je traiter cette semaine et pourquoi?

## Ce que le projet prouve

- capacité à cadrer un problème business
- architecture backend propre
- maîtrise data et IA
- approche MLOps
- capacité à construire un produit complet
