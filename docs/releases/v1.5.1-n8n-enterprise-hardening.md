# v1.5.1 n8n Enterprise Hardening

This release hardens the n8n automation layer for the AI RiskOps Copilot portfolio.

## Highlights

- Added a RiskOps Quality Gate before publishing reports.
- Added retry hardening for external API paths in the n8n workflow.
- Added GitHub labels for generated workflow issues.
- Documented the AI RiskOps Error Handler workflow.
- Added incident issue creation behavior for workflow failures.
- Added a weekly duplicate issue guard before AI generation.
- Added safe skip behavior when a weekly issue already exists.

## Safety

- The exported workflow is safe for manual import.
- Workflow `active` is `false`.
- Schedule Trigger is disabled.
- No real OpenAI keys are committed.
- No real GitHub credentials are committed.
- Reports are expected to use anonymized customer aliases only.

## Expected Skip Response

When a weekly issue already exists for the report date, the workflow returns:

```json
{
  "automation_status": "skipped",
  "reason": "weekly_issue_already_exists"
}
```

In this path, no AI report, OpenAI image or duplicate GitHub issue is generated.
