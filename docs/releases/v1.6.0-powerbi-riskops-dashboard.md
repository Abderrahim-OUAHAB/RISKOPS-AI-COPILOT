# v1.6.0 Power BI RiskOps Executive Dashboard

## Summary

This release adds the `AI RiskOps Executive Dashboard`, a Power BI executive reporting layer for AI RiskOps Copilot.

## Dashboard Features

- Executive KPI cards.
- Risk distribution donut chart.
- Action Board operations by priority, status and owner.
- Top risk customers table using customer aliases.
- Customer risk score analysis.
- Scatter plot for risk score versus confidence.
- Risk drivers frequency analysis.
- AI monitoring page.
- What-if parameter for Risk Score Threshold.
- Customers Above Threshold measure.
- Synced risk level slicers.
- Reset filters bookmarks.
- Customer tooltip page.
- Client 360 drill-through.
- Mobile layout for main pages.
- Conditional formatting for risk level, priority and status.
- Enterprise JSON theme.
- Performance Analyzer export.

## Business Value

The dashboard gives managers an executive view of risk concentration, action pressure, priority accounts and operational follow-up. It complements the Streamlit app with a BI format that is familiar to business stakeholders.

## Technical Value

The release demonstrates API-based Power BI ingestion, report modeling, DAX measures, theming, drill-through, tooltips, mobile layout and performance review.

## Privacy And Security Notes

- Customer-facing visuals use aliases.
- Documentation avoids raw customer identifiers.
- No API credentials are committed.
- Local API endpoints are intended for portfolio validation.

## How To Validate Locally

1. Start the AI RiskOps backend with Docker Compose.
2. Confirm FastAPI docs open at `http://localhost:8000/docs`.
3. Open `docs/powerbi/AI-RiskOps-Executive-Dashboard.pbix` in Power BI Desktop.
4. Click **Refresh**.
5. Review the five main pages and hidden interaction pages.

## Known Limitations

- Power BI Service cannot refresh localhost endpoints without an on-premises data gateway or deployed API endpoint.
- The dashboard is a portfolio artifact, not a governed enterprise workspace deployment.
- Dataset refresh depends on the local FastAPI backend being available.
